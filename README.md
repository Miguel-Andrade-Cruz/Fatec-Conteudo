# Laboratório de hardware

Aqui você terá contato com o grande e vasto mundo maker,
na vertente do arduino, com foco em programação.

Compreensão de componentes básicos, diferentes interfaces
e protocolos para comunicação e controle, e como interconectar
tudo isso com programação são os pontos chaves aprendidos.

Em minha experiência, percebi a grande utilidade fundametalidade invisível
desse conteúdo: Por mais que um analista de sistemas não tenha tal serviço no seu cotidiano,
é nesse momento que se aprende alguns conceitos essenciais:

1. O fluxo "Entrada-Processo-Saída":
  
  Com a sigla EPS, esse fluxo é visto na gigantesca maioria dos sistemas atuais.
  Se baseia em três segmentos:
   
   - Coleta de dados referentes ao objetivo, a Entrada;
   - Composição, comparação e decisão sobre a informação construída, o Processo;
   - Comando, controle e ajuste que foram ordenados, a Saída.
   
   O que mais poderia ser a essência do arduino?
   
2. Métodos de execução

  Aqui eu quero dizer sobre a execução do projeto pedido. Com os desafios descritos,
  há inúmeras maneiras de não só escrevê-lo como fazê-lo.
  
  Saber o que dá para faer primeiro, ao mesmo tempo, o que precisa estar preparado antes,
  conceitos de abstração, tudo isso é desenvolvido ao implementar os deasfios.
  
  
  > *Dúvidas ou não dúvidas*, sempre questione, mesmo parecendo que *está querendo derrubar.*
