Praticar a utilização da linguagem C juntamente com fluxograma
e algoritmos, desenvolvendo a lógica de programação e

capturação e validação de entrada do usuário. Caso deseje saber mais,
vá até o readme da biblioteca localizado em `src/lib/calid`.
